DK 64 CB calculator

This was originally a side-project of Ballaam's that I (jbzdarkid) have taken ownership over, with permission.

The basic idea is that we can (with some effort) fully traverse the randomizer's logical regions (using python),
and use that information to generate a hard-coded list of the requirements for the various colored banana collectibles in each region.

Then, we can show a UX which determines the minimal set of moves required to reach a certain CB count (e.g. 40).
